为什么 ② 跑 25 轮会卡住

    
你做过的实验：x = x * Tensor(1) + x 循环 n 轮，然后 x.backward()。每一轮旧的 x 被用两次，没有 visited 时，每多一轮，递归次数就翻一倍。

    

      

        
轮数 n图里的节点数①② build 调用次数④ build 调用次数

        
      

    

    
①② 的调用次数满足 C(n) = 2·C(n−1) + 3，也就是 2n+2 − 3。④ 里每个节点只展开一次，调用次数是 1 + 所有 _pre 的长度之和 = 4n + 1。② 还有一个额外开销：每次 node not in topo 都要把 list 从头翻一遍。
